Durably Green & Social Claims Scan - v41 replacement package

How to install:
1. Make a backup of your current Durablyagent folder.
2. Unzip this package.
3. Copy agent.py into your Durablyagent folder and replace the old agent.py.
4. If your current main file has another name, first rename the old file as backup, then rename this agent.py to the same filename used by your setup.
5. Start again with: python agent.py

Notes:
- This package is intended to make replacement easier: agent.py already contains the v41 scan.
- The original v41 source is also included as durably_green_social_claims_scan_v41.py for reference.
- Do not run the zip directly. Unzip first, then copy/replace the .py file.
